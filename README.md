# VanKompass (Arbeitstitel) - Vanlife-Hub Entwurf

Erster Entwurf einer KI-automatisierten Affiliate-Hub-Seite fuer Camper-Ausruestung (deutscher Markt). Statische Seite, kein Backend.

**Live-Vorschau:** https://20-sec.github.io/vanlife-hub/

Die Vorschau ist auf `noindex` plus sperrende `robots.txt` gestellt, damit der Entwurf nicht vorzeitig in Suchmaschinen landet. Repo ist oeffentlich (fuer die kostenlose Pages-Vorschau), enthaelt aber nur statisches HTML mit Platzhaltern, keine echten Affiliate-IDs oder Geheimnisse.

## Inhalt

- `index.html` — Hub-Startseite, der "worum willst du dich kuemmern"-Waehler
- `silo-strom.html` — Silo-Pillar Batterie/Strom
- `artikel-powerstation-vw-california-t61.html` — Money-Artikel (13-Block-Template)
- `vanlife-config.js` — zentrale Affiliate-Konfiguration (eine Pflegestelle fuer alle IDs/Links)
- `vanlife-styles.css` — Layout-System
- `LIESMICH.md` — ausfuehrliche Doku, naechste Schritte, Affiliate-Programme

## Status

Entwurf. Produkt-/Preisdaten sind Beispielwerte, Affiliate-IDs Platzhalter, Marke ein Arbeitstitel. Vor Live verifizieren. Details in `LIESMICH.md`.
